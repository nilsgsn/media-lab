# Media Lab – Q1 English (advanced course)

Learning platform for the unit "Media and Literature" (media, social media, journalism, Shakespeare).

- **Learn:** flashcards for three vocabulary tests, discussion phrases, how to present a line of argument
- **Practice:** vocabulary, Discussion Toolkit (choose the best move), Argument Lab (claim, reason, example, concession, rebuttal, conclusion), content quiz
- **Speak:** panel cards with preparation and discussion timer for the group oral exam (part II)
- **Duels and ranking:** challenge classmates; exam groups compete as teams
- **Teacher page:** `teacher.html` (teacher code only)

Plain HTML/CSS/JS, hosted on GitHub Pages; scores in Supabase (EU, Frankfurt). Sign-in with access codes and nicknames, no names or e-mail addresses.
Vocabulary pairs for tests 1–2 follow the Klett *Green Line Oberstufe* vocabulary sheets (Topic 9); all other texts and questions were written for this app.
